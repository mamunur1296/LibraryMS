# LibraryMS Frontend (React + Vite + TypeScript + Tailwind CSS)

This is a standard React application built with Vite, not Next.js.
- Uses `react-router-dom` v7 for routing
- Uses `axios` for HTTP with JWT token refresh queue
- Uses `zod` + `react-hook-form` for form validation
- Environment variables use the `VITE_` prefix (e.g., `VITE_API_URL`)
